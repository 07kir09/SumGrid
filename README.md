# Sum Grid

`Sum Grid` — это браузерная головоломка, в которой нужно отмечать клетки так, чтобы сумма выбранных чисел в каждой строке и каждом столбце точно совпадала с целевыми значениями по краям поля.

## Возможности

- Игровые поля `4x4`, `5x5`, `6x6`, `7x7`
- Выбор сложности
- Подсчёт сумм в реальном времени
- Переключение состояния клетки по кругу:

```text
пусто -> выбрано -> зачеркнуто -> пусто
```

- Определение победы
- Генерация уровней
- Сохранение прогресса через `localStorage`
- Кнопки `Новая игра`, `Сброс`, `Проверить`, `Показать решение`
- Адаптивный тёмный интерфейс для компьютера и телефона

## Управление

- Нажми или тапни по клетке, чтобы изменить её состояние
- Состояния клетки меняются по кругу:

```text
пусто -> выбрано -> зачеркнуто -> пусто
```

- В сумму входят только клетки в состоянии `выбрано`
- Цели для строк показываются справа
- Цели для столбцов показываются снизу
- Головоломка считается решённой только тогда, когда все суммы строк и столбцов точно совпадают с целями

## Ход игры

1. Открой игру
2. Нажми `Начать игру`
3. Отмечай клетки, пока все строки и столбцы не совпадут с целями
4. Используй:
   - `Новая игра` — создать новую головоломку
   - `Сброс` — очистить текущее поле
   - `Проверить` — оценить текущее решение
   - `Показать решение` — показать правильный узор
